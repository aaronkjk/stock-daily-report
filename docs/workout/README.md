# 근비대 3분할 (팔 · 허벅지 집중)

허리디스크를 고려해 스쿼트/데드리프트를 빼고 덤벨·머신으로 구성한 주 3회 근비대 루틴.
세트 기록과 휴식 타이머가 포함된 설치형 웹앱(PWA)이다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (루틴 데이터 · UI · 타이머 · 기록). 외부 의존성 없음 |
| `manifest.webmanifest` | 홈 화면 앱 이름 · 아이콘 · 전체화면 설정 |
| `sw.js` | 오프라인 캐시. 헬스장에서 신호가 약해도 열린다 |
| `icon-*.png` | 홈 화면 아이콘 (180 iOS · 192/512 · maskable 512) |

## 배포

이 레포는 이미 **Settings → Pages** 가 `main` 브랜치 `/docs` 폴더로 설정돼 있고,
매일 아침 주식 리포트가 그 주소로 나간다. 이 앱은 그 안의 `docs/workout/` 에
들어가므로 **Pages 설정을 바꿀 필요가 없다.** `main` 에 올라가면 1~2분 뒤 열린다.

```
https://aaronkjk.github.io/stock-daily-report/workout/
```

Pages Source 를 `/(root)` 로 바꾸면 기존 리포트 주소가 깨지니 건드리지 말 것.
모든 경로가 상대 경로(`./sw.js` 등)라 서브디렉터리에서 그대로 동작한다.

## 아이폰 홈 화면에 추가

1. **Safari** 로 위 주소를 연다. (크롬 등 다른 브라우저에서는 설치가 안 된다)
2. 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체화면으로 뜨고, 오프라인에서도 열린다.

## 루틴을 수정할 때

`index.html` 상단의 `P` 배열이 프로그램 전체다. 종목 하나는 이렇게 생겼다.

```js
{ n:"레그 프레스", en:"Leg Press", pri:true, sets:4, reps:"8–12", rest:180,
  note:"...", safe:"..." }
```

| 키 | 의미 |
|---|---|
| `sets` | 세트 수. 입력 행이 이 수만큼 생성된다 |
| `reps` | 목표 반복 구간 (표시용) |
| `rest` | 휴식 초. ✓ 를 누르면 이 값으로 타이머가 자동 시작된다 |
| `pri` | 우선 부위(팔/허벅지) 뱃지 표시 |
| `opt` | 시간 부족 시 생략 가능 표시 |
| `note` / `safe` | 수행 포인트 / 허리 주의 (HTML 태그 사용 가능) |

내용을 고친 뒤에는 `sw.js` 의 `CACHE` 값을 올려야(`gym-routine-v1` → `v2`)
이미 설치한 기기에 "새 버전이 있습니다" 알림이 뜬다.

## 기록 저장

무게·횟수는 `localStorage` 에 저장되므로 그 기기·그 브라우저에만 남는다.
서버로 전송되지 않고, 완료 체크는 날짜가 바뀌면 자동 초기화된다.
